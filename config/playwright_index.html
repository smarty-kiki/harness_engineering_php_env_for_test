测试过程
◉ 实时画面
只读 noVNC 画面，playwright-run 执行时可直接观察浏览器操作。不可远程接管。 /vnc/vnc.html?autoconnect=true&resize=scale&view_only=true
⌁ Trace Viewer
最近一次运行的 Playwright trace：动作、DOM 快照、网络与 Console。 /trace
运行产物
▤ 最近一次运行
trace.zip、录像、截图、覆盖率事件与 meta.json，按运行独立归档。 /artifacts/latest/
▥ 历史运行
所有历史运行目录，可下载旧 trace.zip 在本地用 Playwright 打开。 /artifacts/runs/
覆盖率报告
◧ 前端覆盖率
最近一次运行的 V8 精确覆盖率，按运行独立统计，含行内脚本。 /coverage/
◨ 后端覆盖率
PHP 覆盖率 HTML 快照，执行 coverage-report --html 后更新。 /php-coverage/
◫ 覆盖率总览
同一页切换前端与后端报告；两套口径不同，数字不能相加。 /reports/
常用命令：playwright-run /tmp/flow.js --root /var/www/project_manage_system 运行测试；frontend-coverage-report --html 重新生成前端报告； coverage-report --html 发布后端报告。 宿主机访问需在启动容器时映射 -p 8080:8080。
